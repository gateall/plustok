# 작업지시서: 통합 로그인 + 아이디/비밀번호 찾기 (2026-07-22)

**상태:** 코드 완료 · **DB 마이그레이션 + FTP 배포 필요**
**의도:** 로그인 화면을 하나로 통합하고(불가능하면 두 번째 로그인은 자동 통과), 아이디/비밀번호 찾기 제공

---

## 1. 의도 (왜)

- Admin 패널(`/admin/`)과 Frontend(`/frontend/#/login`)가 각자 로그인 화면을 갖고 있어 혼란스러움 → **로그인 화면은 하나만 남긴다.**
- 두 화면을 물리적으로 한 코드베이스로 합치는 건 무리(PHP 서버 렌더링 vs React SPA) → **차선책으로 두 번째 로그인(Admin)은 화면 없이 세션 체크만 하고 자동으로 넘어가게** 한다.
- 로그인 실패 시 사용자가 막히지 않도록 아이디/비밀번호 찾기를 이메일 기반으로 제공한다.

## 2. 구현 방식 (선택한 접근)

**단일 로그인 화면 = `/frontend/#/login`**

1. `admin/index.php`: 로그인 안 된 상태로 GET 접근하면 자체 로그인 폼을 보여주지 않고 `/frontend/#/login`으로 리다이렉트. (POST 처리 로직은 하위호환으로 남겨둠 — 이제 UI에서 쓰이진 않음)
2. `/frontend/#/login`에서 로그인 성공 시, 응답의 `agent.role`을 확인:
   - `agent`/기타 → 기존처럼 `/chat`으로 이동
   - `admin`/`operator` → 새로 만든 `admin/sso.php`(JWT 검증 → PHP 세션 생성)를 호출한 뒤 `/admin/dashboard.php`로 **자동 이동** (비밀번호 재입력 없음)

이렇게 "로그인 화면 1개 + 두 번째 진입점은 체크만 하고 통과"가 완성됨.

## 3. 아이디/비밀번호 찾기 (이메일 방식)

- `agents.email`(암호화 저장)을 기준으로:
  - **아이디 찾기** (`/find-id`): 이름 + 이메일 입력 → 일치하면 이메일로 `login_id` 발송
  - **비밀번호 찾기** (`/forgot-password`): 아이디 + 이메일 입력 → 일치하면 재설정 링크(`#/reset-password?token=`) 이메일 발송, 30분 유효
- 계정 존재 여부를 노출하지 않기 위해 **항상 "발송했습니다" 메시지만 표시** (일치 여부와 무관)
- 발신은 `config/app.php`의 `MAIL_FROM` 사용 (PHP `mail()`)
- 로그인 화면 하단에 "아이디 찾기 | 비밀번호 찾기" 링크 추가

## 5. 배포 순서

### STEP 1. phpMyAdmin — DB
```sql
-- 계정 잠금 있으면 해제
UPDATE agents SET failed_login_count = 0, locked_until = NULL WHERE login_id = 'admin';

-- 재설정 토큰 컬럼 (아직 안 했으면)
ALTER TABLE agents ADD COLUMN reset_token_hash CHAR(64) NULL AFTER locked_until;
ALTER TABLE agents ADD COLUMN reset_token_expires_at DATETIME(3) NULL AFTER reset_token_hash;
ALTER TABLE agents ADD KEY idx_agents_reset_token (reset_token_hash);
```

### STEP 2. FTP — 백엔드
- `admin/index.php`
- `admin/sso.php` (신규)
- `includes/services/AuthService.php`
- `includes/repositories/AgentRepository.php`
- `api/v1/router.php`
- `config/acep.php`

### STEP 3. FTP — 프론트엔드
- `frontend-upload.zip` 내용물 → `/www/frontend/` (기존 assets 삭제 후 교체)
- ⚠️ `frontend/tmp-login-admin.json`(테스트용, admin 평문 비밀번호 포함)은 **업로드 금지 + 삭제**

### STEP 4. agents.email 등록 (비밀번호/아이디 찾기 쓰려면 필수)
브라우저 콘솔에서 (admin으로 로그인 후):
```js
fetch('/api/v1/agents/me/profile', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json', Authorization: 'Bearer ' + accessToken },
  body: JSON.stringify({ email: 'your@email.com' }),
});
```
