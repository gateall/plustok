# 로그인 500 에러 (`MSG_SEND_FAILED`) — DB 마이그레이션 + 계정 통합 (2026-07-22)

**상태:** 원인 확정 · **phpMyAdmin SQL 실행 + FTP 코드 배포 필요**
**대상:** `https://plustok.mycafe24.com/api/v1/auth/login`

---

## 1. 원인 (확정)

`GET /api/v1/system/health` 로 직접 확인 완료:

```json
{"components":{"agents":{"status":"down"}},"hint":"Frontend login requires agents table — run migrations/V1.5.0__agents_ai_ops.sql"}
```

`agents` 테이블이 운영 DB에 없어서 로그인 쿼리가 `PDOException` → 미처리 예외로 흘러 `MSG_SEND_FAILED`(범용 500)로 마스킹됨.

**SSH/CLI 접근 불가 확인됨** (SSH 키/config 없음, FTP만 가능) → `php migrations/migrate.php` 를 서버에서 직접 실행할 수 없음. **phpMyAdmin에서 SQL 파일을 직접 실행**하는 방식으로 진행.

## 2. 계정 정책 결정 (확정)

Admin(`managers`, 그누보드/관리자 사이트) 계정과 Frontend 상담원(`agents`) 계정을 **통합**하기로 결정. 즉 기존 admin 계정의 login_id/비밀번호 해시를 그대로 `agents`에 복사해서, 같은 자격증명으로 admin 사이트와 상담원 프론트엔드 양쪽에 로그인 가능하게 함.

## 3. 실행 순서 (phpMyAdmin, Cafe24 패널)

**순서 중요 — 반드시 아래 순서대로, 각 단계 실행 전 DB 백업 권장**

### 3-1. `agents` 등 스키마 생성
```
migrations/V1.5.0__agents_ai_ops.sql
```
(9개 테이블 + `customer_bridge` 생성. 이미 일부 존재하면 에러 날 수 있으니 `--check` 결과 없이 진행 시 테이블별로 `CREATE TABLE IF NOT EXISTS` 여부 직접 확인)

### 3-2. Admin → agents 계정 복사
```
migrations/seed_agents_from_managers.sql
```
`managers` 테이블에서 `status=1`인 계정의 login_id/password_hash를 `agents`로 복사 (role 매핑: super/admin→admin, manager→operator, 나머지→agent). 이미 존재하는 login_id는 건너뜀(`NOT EXISTS` 체크 있음).

### 3-3. 백엔드 코드 FTP 재배포
다음 파일을 FTP로 덮어쓰기:
- `includes/services/AuthService.php` (PDO/Audit/JWT 단계별 에러 코드 세분화, audit_logs 없어도 로그인 허용)
- `api/v1/router.php` (`/system/health`에 agents/audit_logs 컴포넌트 상태 추가)

### 3-4. (선택) JWT 시크릿 확인
`config/acep.local.php` → `ACEP_JWT_SECRET` 설정 확인 (없으면 dev 기본값 사용 — 운영에선 반드시 설정 권장)

## 4. 검증

```bash
curl -s https://plustok.mycafe24.com/api/v1/system/health
```
→ `agents.status: up`, `hint: null` 확인

```bash
curl -X POST https://plustok.mycafe24.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"loginId":"<기존 admin 계정 ID>","username":"<기존 admin 계정 ID>","password":"<기존 admin 비밀번호>"}'
```
→ `success:true` + `accessToken` 반환되면 완료. 브라우저에서 `#/login` 실제 로그인도 확인.
