## 1. 동기화 아키텍처

### 1.1 Dual-Path Model

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        DUAL-PATH SYNC MODEL                              │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  [Write Path — Client]                                                   │
│    POST /api/v1/chats/{id}/messages  ──► Backend ──► MariaDB (SoT)      │
│                                                                          │
│  [Notify Path — Server]                                                  │
│    Backend PUBLISH Redis ──► Chat Server ──► WS message:receive         │
│                                                                          │
│  [Read Path — Client]                                                    │
│    Initial: GET /messages (paginated)                                    │
│    Live:    WS events → React Query cache patch                          │
│    Gap:     GET /messages?before= on reconnect                           │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1.2 Source of Truth Matrix

| Data Domain | Source of Truth | Real-time Notify | Client Cache Key |
|-------------|-----------------|------------------|------------------|
| Messages | `chat_messages` (MariaDB) | `message:receive` | `['messages', roomId]` |
| Read status | `chat_read_status` | `read:update` | embedded in messages |
| AI recommendations | `ai_recommendations` | `ai:update` | `['ai', 'recommendations', roomId]` |
| Room list | `chat_rooms` + aggregates | `room:update` | `['rooms', filters]` |
| Typing | ephemeral (in-memory) | `typing:*` | local component state |
| Unread count | computed from read_status | `room:update.unreadCount` | rooms query |

### 1.3 React Query Cache Architecture

```typescript

export const queryKeys = {
  rooms: (filters?: { status?: string; search?: string }) =>
    ['rooms', filters ?? {}] as const,
  messages: (roomId: string) => ['messages', roomId] as const,

```

| Hook | Query Key | staleTime | WS Invalidation |
|------|-----------|-----------|-----------------|
| useChatRooms | rooms(filters) | 15s | room:update, message:receive |
| useMessages | messages(roomId) | 5s | message:receive, read:update |
| useAiRecommendations | aiRecommendations(roomId) | 10s | ai:update completed |
| useSocket | — | — | all above handlers |

## 2. 메시지 동기화

### 2.1 Send Flow (Agent — V1.0 REST Primary)

```
InputField onSubmit
    │
    ├─ 1. Generate tempId = `temp-${Date.now()}-${random}`
    │
    ├─ 2. Optimistic insert (onMutate)
    │      queryClient.setQueryData(messages, [...old, optimisticMsg])
    │      optimisticMsg.readStatus = 'sent'
    │
    ├─ 3. POST /api/v1/chats/{roomId}/messages
    │      Body: { content, tempId?, attachmentId? }
    │      Response 201: { messageId, createdAt }
    │
    ├─ 4. Backend INSERT chat_messages
    │      Backend INSERT chat_read_status (delivered_at)
    │      Backend PUBLISH message:receive (includes tempId)
    │
    ├─ 5. WS message:receive → all clients in room
    │      Replace optimistic by tempId match
    │      OR append if no tempId (peer message)
    │
    └─ 6. onSuccess: invalidate rooms (lastMessage preview)
```

### 2.2 useMessages Optimistic Implementation

```typescript
const sendMutation = useMutation({
  mutationFn: async (body: SendMessageRequest & { tempId?: string }) => {
    return api.post(`/chats/${roomId}/messages`, body);
  },
  onMutate: async (variables) => {
    const tempId = variables.tempId ?? `temp-${Date.now()}`;
    await queryClient.cancelQueries({ queryKey: queryKeys.messages(roomId!) });

    const optimistic: ChatMessage = {
      id: tempId,
      tempId,
      roomId: roomId!,
      senderType: 'agent',
      senderId: currentAgentId,
      content: variables.content,
      createdAt: new Date().toISOString(),
      readStatus: 'sent',
    };

    queryClient.setQueryData<ChatMessage[]>(queryKeys.messages(roomId!), (old = []) => [
      ...old,
      optimistic,
    ]);

    return { tempId };
  },
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: queryKeys.rooms() });
  },
  onError: (error, _vars, context) => {
    if (!roomId || !context?.tempId) return;
    queryClient.setQueryData<ChatMessage[]>(queryKeys.messages(roomId), (old = []) =>
      old.map((m) => (m.tempId === context.tempId ? { ...m, failed: true } : m))
    );
    showApiError(error);
  },
});
```

### 2.3 Message Receive (WebSocket)

```typescript
// useSocket handleMessageReceive
const handleMessageReceive = (msg: MessageReceivePayload) => {
  queryClient.setQueryData<ChatMessage[]>(queryKeys.messages(msg.roomId), (old = []) => {
    // Case 1: Replace optimistic message
    if (msg.tempId) {
      const idx = old.findIndex((m) => m.tempId === msg.tempId);
      if (idx >= 0) {
        const next = [...old];
        next[idx] = mapWsMessageToChatMessage(msg);
        return next;
      }
    }
    // Case 2: Dedup by messageId
    if (old.some((m) => m.id === msg.messageId)) return old;
    // Case 3: Append new message
    return [...old, mapWsMessageToChatMessage(msg)];
  });
  queryClient.invalidateQueries({ queryKey: queryKeys.rooms() });
};
```

### 2.4 Message Ordering Guarantees

| Guarantee | Mechanism |
|-----------|-----------|
| Per-room total order | `chat_messages.created_at` ASC (microsecond precision DATETIME(3)) |
| Client display order | sort by `createdAt` after flatMap pages |
| Duplicate prevention | dedup by `messageId` in WS handler |
| Optimistic ordering | append at end; replace in-place on confirm |
| Cross-client consistency | server assigns `messageId` + `created_at` |

### 2.5 Conflict Resolution

| Scenario | Resolution |
|----------|------------|
| Same tempId, two WS events | idempotent replace (same messageId) |
| Optimistic + WS without tempId | dedup by content+timestamp within 1s window (fallback) |
| REST 201 but WS missed | reconnect gap fill via GET messages |
| REST failed, optimistic exists | mark `failed: true`, show retry button |
| Out-of-order WS (rare) | insert by createdAt sort on every cache update |

### 2.6 Message Pagination & History

```typescript
// GET /api/v1/chats/{roomId}/messages?limit=50&before={iso8601}
const query = useInfiniteQuery({
  queryKey: queryKeys.messages(roomId),
  queryFn: ({ pageParam }) =>
    api.get(`/chats/${roomId}/messages?limit=50&before=${pageParam ?? ''}`),
  getNextPageParam: (lastPage) => {
    if (!lastPage.hasMore) return undefined;
    return lastPage.messages[lastPage.messages.length - 1]?.createdAt;
  },
  initialPageParam: undefined,
});
```

| Param | Description |
|-------|-------------|
| limit | default 50, max 100 |
| before | cursor — messages older than this timestamp |
| hasMore | boolean in response |

**Merge strategy:** WS live messages append to newest page; scroll-up triggers `fetchNextPage`.

## 3. 읽음 표시 (Read Receipts)

### 3.1 State Model

```
readStatus enum (Client):
  sent      → optimistic, not yet confirmed
  delivered → ✓  (chat_read_status.delivered_at set)
  read      → ✓✓ (chat_read_status.read_at set)
```

### 3.2 Business Rules (UI Doc §7.1)

| Rule ID | 설명 | Implementation |
|---------|------|----------------|
| BR-READ-001 | 메시지 수신 즉시 ✓ (delivered) | Backend INSERT read_status on message INSERT |
| BR-READ-002 | room 활성화 시 ✓✓ (read) | useReadReceipt → PUT /read |
| BR-READ-003 | 자동 read 금지 — room focus 필요 | effect runs only when room selected |
| BR-READ-004 | closed room read API skip | `if (roomStatus === 'closed') return` |

### 3.3 Read Flow Diagram

```
메시지 수신 (WS message:receive)
    ↓
Backend: INSERT chat_read_status (delivered_at = NOW())
    ↓
Agent UI: MessageBubble shows ✓ (delivered)
    ↓
Agent selects room / focuses chat panel
    ↓
useReadReceipt: filter unread customer messages
    ↓
PUT /api/v1/chats/{id}/read { messageIds, readerType: "agent" }
    ↓
Backend: UPDATE chat_read_status.read_at = NOW()
Backend: PUBLISH read:update
    ↓
Customer UI: MessageBubble ✓✓ (read)
Agent UI: local cache patch (read:update or PUT success)
```

### 3.4 useReadReceipt Implementation

```typescript
export function useReadReceipt(
  roomId: string | null,
  messages: ChatMessage[],
  roomStatus?: string
) {
  const markedRef = useRef<Set<string>>(new Set());

  const mutation = useMutation({
    mutationFn: (body: ReadReceiptRequest) =>
      api.put(`/chats/${roomId}/read`, body),
  });

  const markAsRead = useCallback((messageIds: string[]) => {
    if (!roomId || roomStatus === 'closed') return;
    const unread = messageIds.filter((id) => !markedRef.current.has(id));
    if (unread.length === 0) return;
    unread.forEach((id) => markedRef.current.add(id));
    mutation.mutate({ messageIds: unread, readerType: 'agent' });
  }, [roomId, roomStatus, mutation]);

  useEffect(() => {
    if (!roomId || !messages.length) return;
    const unreadCustomerIds = messages
      .filter((m) => m.senderType === 'customer' && m.readStatus !== 'read')
      .map((m) => m.id);
    if (unreadCustomerIds.length > 0) markAsRead(unreadCustomerIds);
  }, [roomId, messages, markAsRead]);

  return { markAsRead, isUpdating: mutation.isPending };
}
```

### 4.2 MessageService Write Sequence

```php
// MessageService::sendMessage()
public function sendMessage(string $roomId, array $dto): array
{
    $messageId = uuid_v4();
    $this->messageRepo->insert([
        'id' => $messageId,
        'room_id' => $roomId,
        'sender_type' => $dto['senderType'],
        'sender_id' => $dto['senderId'],
        'content' => $dto['content'],
        'created_at' => now_ms(),
    ]);

    // BR-READ-001: delivered status for peer
    $this->readStatusRepo->insertDelivered($roomId, $messageId, $peerReader);

    // Notify via Redis
    redis_publish_room_event($roomId, 'message:receive', [
        'messageId' => $messageId,
        'roomId' => $roomId,
        'content' => $dto['content'],
        'senderType' => $dto['senderType'],
        'senderId' => $dto['senderId'],
        'timestamp' => iso8601(now()),
        'tempId' => $dto['tempId'] ?? null,
    ]);

    // AI trigger (customer messages only)
    if ($dto['senderType'] === 'customer') {
        $this->aiService->enqueueAnalysis($roomId, $messageId);
    }

    return ['messageId' => $messageId];
}
```

### 5.2 ReadStatusService

```php
public function markRead(string $roomId, array $messageIds, string $readerType, string $readerId): int
{
    $count = 0;
    foreach ($messageIds as $messageId) {
        $updated = $this->readStatusRepo->updateReadAt(
            $messageId, $readerType, $readerId, now_ms()
        );
        if ($updated) {
            $count++;
            redis_publish_room_event($roomId, 'read:update', [
                'roomId' => $roomId,
                'messageId' => $messageId,
                'readerType' => $readerType,
                'readAt' => iso8601(now()),
            ]);
        }
    }
    return $count;
}
```

### 5.3 Unread Count Computation

```sql
-- ChatList unreadCount per room (agent view)
SELECT cr.id AS room_id,
       COUNT(cm.id) AS unread_count
FROM chat_rooms cr
JOIN chat_messages cm ON cm.room_id = cr.id AND cm.sender_type = 'customer'
LEFT JOIN chat_read_status crs ON crs.message_id = cm.id
    AND crs.reader_type = 'agent'
    AND crs.reader_id = :agentId
    AND crs.read_at IS NOT NULL
WHERE cr.agent_id = :agentId
  AND cr.status IN ('new', 'active')
  AND crs.id IS NULL
GROUP BY cr.id;
```

**Real-time update:** Backend recalculates on PUT /read → PUBLISH `room:update { unreadCount }`.

## 6. Typing Indicator 동기화

### 6.1 Rules (BR-TYPE-001~004)

| Rule | Client Behavior | Server Behavior |
|------|-----------------|-----------------|
| BR-TYPE-001 | InputField onInput → emit typing:start | relay to room peers |
| BR-TYPE-002 | 3s idle → emit typing:stop | relay |
| BR-TYPE-003 | message send → emit typing:stop | relay |
| BR-TYPE-004 | indicator shown to peer only | `socket.to(room).emit` |

### 6.2 useTyping Implementation

```typescript
export function useTyping(roomId: string | null) {
  const [isTyping, setIsTyping] = useState(false);
  const [typingUser, setTypingUser] = useState<string | null>(null);
  const idleTimerRef = useRef<NodeJS.Timeout>();
  const isTypingRef = useRef(false);

  useEffect(() => {
    const socket = getSocket();
    if (!socket || !roomId) return;

    const onStart = (p: TypingPayload) => {
      if (p.userId === currentUserId) return; // BR-TYPE-004
      setIsTyping(true);
      setTypingUser(p.userName ?? '상대방');
    };
    const onStop = () => {
      setIsTyping(false);
      setTypingUser(null);
    };

    socket.on('typing:start', onStart);
    socket.on('typing:stop', onStop);
    return () => {
      socket.off('typing:start', onStart);
      socket.off('typing:stop', onStop);
    };
  }, [roomId]);

  const emitTypingStart = useCallback(() => {
    const socket = getSocket();
    if (!socket?.connected || !roomId) return;
    if (!isTypingRef.current) {
      socket.emit('typing:start', { roomId });
      isTypingRef.current = true;
    }
    clearTimeout(idleTimerRef.current);
    idleTimerRef.current = setTimeout(() => emitTypingStop(), 3000);
  }, [roomId]);

  const emitTypingStop = useCallback(() => {
    const socket = getSocket();
    if (!socket?.connected || !roomId) return;
    clearTimeout(idleTimerRef.current);
    if (isTypingRef.current) {
      socket.emit('typing:stop', { roomId });
      isTypingRef.current = false;
    }
  }, [roomId]);

  return { isTyping, typingUser, emitTypingStart, emitTypingStop };
}
```

```typescript
export function useAiRecommendations(roomId: string | null) {
  const query = useQuery({
    queryKey: queryKeys.aiRecommendations(roomId ?? ''),
    queryFn: () => api.get(`/ai/recommendations/${roomId}`),
    enabled: !!roomId,
    staleTime: 10_000,
    refetchInterval: (query) => {
      // Fallback polling if ai:update missed (2s for 30s max)
      if (query.state.data?.status === 'processing') return 2000;
      return false;
    },
  });

  return {
    recommendations: query.data?.recommendations ?? [],
    contractProbability: query.data?.contractProbability,
    sentiment: query.data?.sentiment,
    status: query.data?.status ?? 'idle',
    isLoading: query.isLoading,
    isFailed: query.data?.status === 'failed',
    refetch: query.refetch,
  };
}
```

```typescript
// src/utils/offlineQueue.ts
const QUEUE_KEY = 'acep_offline_msg_queue';
const MAX_QUEUE = 100;

interface QueuedMessage {
  roomId: string;
  content: string;
  tempId: string;
  createdAt: string;
}

export function enqueueOfflineMessage(msg: QueuedMessage): void {
  const queue = getQueue();
  if (queue.length >= MAX_QUEUE) {
    queue.shift(); // drop oldest
    console.warn('Offline queue full, dropped oldest message');
  }
  queue.push(msg);
  localStorage.setItem(QUEUE_KEY, JSON.stringify(queue));
}

export async function flushOfflineQueue(api: ApiClient): Promise<void> {
  const queue = getQueue();
  const remaining: QueuedMessage[] = [];

  for (const msg of queue) {
    try {
      await api.post(`/chats/${msg.roomId}/messages`, {
        content: msg.content,
        tempId: msg.tempId,
      });
    } catch {
      remaining.push(msg);
    }
  }

  localStorage.setItem(QUEUE_KEY, JSON.stringify(remaining));
}
```

### 9.2 Disconnect Send Handling

```
User clicks Send while disconnected
    ↓
enqueueOfflineMessage({ roomId, content, tempId })
Show optimistic message with "pending sync" indicator
    ↓
On reconnect (useSocket onConnect)
    ↓
flushOfflineQueue()
Each success → WS message:receive replaces optimistic
Each failure → mark failed + retry button
```

### 9.3 Reconnect Sync Sequence

```typescript
async function syncAfterReconnect(roomId: string, queryClient: QueryClient) {
  // 1. Re-join room
  getSocket()?.emit('room:join', { roomId });

  // 2. Gap fill messages
  await queryClient.invalidateQueries({ queryKey: queryKeys.messages(roomId) });

  // 3. AI state
  await queryClient.invalidateQueries({ queryKey: queryKeys.aiRecommendations(roomId) });

  // 4. Room list
  await queryClient.invalidateQueries({ queryKey: queryKeys.rooms() });

  // 5. Flush offline queue
  await flushOfflineQueue(api);
}
```
