## 1. 설계 원칙

### 1.1 네이밍 규칙

| 규칙 | 예시 |
|------|------|
| 테이블/컬럼 | snake_case |
| PK | `id` (VARCHAR(36) UUID 또는 BIGINT AUTO_INCREMENT) |
| FK | `{entity}_id` |
| 타임스탬프 | `created_at`, `updated_at`, `deleted_at` |
| Soft Delete | `deleted_at DATETIME NULL` (물리 삭제 금지) |
| ENUM | 소문자 snake 또는 MASTER/UI 문서와 동일 값 |

### 1.2 공통 컬럼 패턴

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `created_at` | DATETIME(3) | INSERT 시 `CURRENT_TIMESTAMP(3)` |
| `updated_at` | DATETIME(3) | UPDATE 시 ON UPDATE |
| `deleted_at` | DATETIME(3) NULL | Soft delete, GDPR anonymize 시 사용 |

### 1.3 PII 암호화 (MASTER PART 9.3)

| 컬럼 | 암호화 | 표시 (UI) |
|------|--------|-----------|
| `customers.phone` | AES-256-GCM (앱 레벨) | `010-****-5678` → `CustomerCard.phoneMasked` |
| `customers.email` | AES-256-GCM | `user@****.com` → `CustomerCard.emailMasked` |
| `customers.address` | AES-256-GCM | `서울시 강남구 ****` → `CustomerCard.addressMasked` |
| `agents.email` | AES-256-GCM | Admin 화면 마스킹 |
| `agents.phone` | AES-256-GCM | Admin 화면 마스킹 |

- 암호화 키: 환경변수 `PII_ENCRYPTION_KEY` (32바이트, KMS/Vault 권장)
- DB에는 Base64 인코딩된 ciphertext 저장 (`VARCHAR(512)`)
- 검색용 해시: `phone_hash` SHA-256 (선택, 중복 고객 매칭)


## 5. 테이블 상세 및 DDL

### 5.1 customers (고객)

**목적:** 채팅 접수 시 생성·매칭되는 고객 마스터. `CustomerCard` 데이터 소스.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| name | VARCHAR(100) | NOT NULL | 표시명 |
| phone | VARCHAR(512) | NOT NULL | **AES-256 암호화** |
| phone_hash | CHAR(64) | NULL, INDEX | SHA-256, 중복 검색 |
| email | VARCHAR(512) | NULL | **AES-256 암호화** |
| address | TEXT | NULL | **AES-256 암호화** |
| tags | JSON | NULL | `["신규","고가","긍정"]` |
| consultation_count | INT UNSIGNED | DEFAULT 0 | 상담 횟수 |
| external_crm_id | VARCHAR(100) | NULL | PLUS톡 V2.0 CRM 연동 ID |
| created_at | DATETIME(3) | NOT NULL | - |
| updated_at | DATETIME(3) | NOT NULL | - |
| deleted_at | DATETIME(3) | NULL | Soft delete |

```sql
CREATE TABLE customers (
    id              VARCHAR(36)     NOT NULL,
    name            VARCHAR(100)    NOT NULL,
    phone           VARCHAR(512)    NOT NULL COMMENT 'AES-256-GCM encrypted',
    phone_hash      CHAR(64)        NULL COMMENT 'SHA-256 for lookup',
    email           VARCHAR(512)    NULL COMMENT 'AES-256-GCM encrypted',
    address         TEXT            NULL COMMENT 'AES-256-GCM encrypted',
    tags            JSON            NULL,
    consultation_count INT UNSIGNED NOT NULL DEFAULT 0,
    external_crm_id VARCHAR(100)    NULL,
    created_at      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    deleted_at      DATETIME(3)     NULL,
    PRIMARY KEY (id),
    KEY idx_customers_phone_hash (phone_hash),
    KEY idx_customers_created_at (created_at),
    KEY idx_customers_deleted_at (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='고객 마스터 — CustomerCard';
```

### 5.2 chat_rooms (상담방)

**목적:** 1 상담 세션 = 1 room. `ChatList` 정렬·필터 기준.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| customer_id | VARCHAR(36) | FK, NOT NULL | → customers.id |
| agent_id | VARCHAR(36) | FK, NULL | → agents.id (V1.5+) |
| inquiry_type | VARCHAR(50) | NOT NULL | 인터넷, CCTV, 대표번호 |
| status | ENUM | NOT NULL | `new`, `active`, `closed` |
| channel | VARCHAR(30) | NOT NULL | web, phone, kakao |
| subject | VARCHAR(200) | NULL | room header 표시 |
| memo | TEXT | NULL | Footer 메모 |
| priority_score | TINYINT UNSIGNED | DEFAULT 0 | AI 계약확률 캐시 |
| created_at | DATETIME(3) | NOT NULL | - |
| updated_at | DATETIME(3) | NOT NULL | ChatList 정렬 |
| closed_at | DATETIME(3) | NULL | 상담 종료 시각 |
| deleted_at | DATETIME(3) | NULL | - |

```sql
CREATE TABLE chat_rooms (
    id              VARCHAR(36)     NOT NULL,
    customer_id     VARCHAR(36)     NOT NULL,
    agent_id        VARCHAR(36)     NULL,
    inquiry_type    VARCHAR(50)     NOT NULL,
    status          ENUM('new','active','closed') NOT NULL DEFAULT 'new',
    channel         VARCHAR(30)     NOT NULL DEFAULT 'web',
    subject         VARCHAR(200)    NULL,
    memo            TEXT            NULL,
    priority_score  TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '0-100 contract cache',
    created_at      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    closed_at       DATETIME(3)     NULL,
    deleted_at      DATETIME(3)     NULL,
    PRIMARY KEY (id),
    KEY idx_chat_rooms_status_updated (status, updated_at DESC),
    KEY idx_chat_rooms_customer (customer_id),
    KEY idx_chat_rooms_agent (agent_id),
    KEY idx_chat_rooms_priority (priority_score DESC, updated_at DESC),
    CONSTRAINT fk_chat_rooms_customer
        FOREIGN KEY (customer_id) REFERENCES customers(id),
    CONSTRAINT fk_chat_rooms_agent
        FOREIGN KEY (agent_id) REFERENCES agents(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='상담방 — ChatList, StatusBadge';
```

> **V1.0 마이그레이션:** `agent_id` FK는 `agents` 테이블 생성 후 ALTER ADD CONSTRAINT.

### 5.3 chat_messages (메시지)

**목적:** 실시간 채팅 메시지. `MessageBubble` 렌더 소스.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| room_id | VARCHAR(36) | FK, NOT NULL | → chat_rooms.id |
| sender_type | ENUM | NOT NULL | `customer`, `agent`, `system` |
| sender_id | VARCHAR(36) | NOT NULL | customers/agents UUID |
| content | TEXT | NOT NULL | 본문 (max 2000자 앱 검증) |
| attachment_url | VARCHAR(500) | NULL | 레거시/직접 URL |
| attachment_id | VARCHAR(36) | FK, NULL | → attachments.id (V1.5+) |
| attachment_type | VARCHAR(20) | NULL | image, pdf |
| source | ENUM | DEFAULT 'manual' | manual, ai_recommendation |
| ai_recommendation_id | VARCHAR(36) | NULL | 채택한 추천 ID |
| created_at | DATETIME(3) | NOT NULL | MessageBubble timestamp |
| deleted_at | DATETIME(3) | NULL | - |

```sql
CREATE TABLE chat_messages (
    id                      VARCHAR(36)     NOT NULL,
    room_id                 VARCHAR(36)     NOT NULL,
    sender_type             ENUM('customer','agent','system') NOT NULL,
    sender_id               VARCHAR(36)     NOT NULL,
    content                 TEXT            NOT NULL,
    attachment_url          VARCHAR(500)    NULL,
    attachment_id           VARCHAR(36)     NULL,
    attachment_type         VARCHAR(20)     NULL,
    source                  ENUM('manual','ai_recommendation') NOT NULL DEFAULT 'manual',
    ai_recommendation_id    VARCHAR(36)     NULL,
    created_at              DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    deleted_at              DATETIME(3)     NULL,
    PRIMARY KEY (id),
    KEY idx_chat_messages_room_created (room_id, created_at DESC),
    KEY idx_chat_messages_sender (sender_type, sender_id),
    KEY idx_chat_messages_attachment (attachment_id),
    CONSTRAINT fk_chat_messages_room
        FOREIGN KEY (room_id) REFERENCES chat_rooms(id),
    CONSTRAINT fk_chat_messages_attachment
        FOREIGN KEY (attachment_id) REFERENCES attachments(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='채팅 메시지 — MessageBubble';
```

### 5.4 ai_recommendations (AI 추천)

**목적:** AI Router 출력 저장. `AIPanelCard`, `RecommendationCard` 데이터.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| room_id | VARCHAR(36) | FK, NOT NULL | → chat_rooms.id |
| type | ENUM | NOT NULL | answer, faq, analysis, contract |
| content | JSON | NOT NULL | 추천 payload 전체 |
| contract_probability | TINYINT UNSIGNED | NULL | 0~100 |
| sentiment | ENUM | NULL | positive, neutral, negative |
| intent | VARCHAR(30) | NULL | purchase, inquiry, complaint |
| status | ENUM | NOT NULL | pending, processing, completed, failed |
| ai_model | VARCHAR(50) | NULL | claude-3.5-sonnet 등 |
| prompt_version | VARCHAR(20) | NULL | PROMPT_RECOMMEND_v1.0 |
| latency_ms | INT UNSIGNED | NULL | 응답 시간 |
| created_at | DATETIME(3) | NOT NULL | - |

```sql
CREATE TABLE ai_recommendations (
    id                      VARCHAR(36)     NOT NULL,
    room_id                 VARCHAR(36)     NOT NULL,
    type                    ENUM('answer','faq','analysis','contract') NOT NULL DEFAULT 'answer',
    content                 JSON            NOT NULL,
    contract_probability    TINYINT UNSIGNED NULL,
    sentiment               ENUM('positive','neutral','negative') NULL,
    intent                  VARCHAR(30)     NULL,
    status                  ENUM('pending','processing','completed','failed') NOT NULL DEFAULT 'pending',
    ai_model                VARCHAR(50)     NULL,
    prompt_version          VARCHAR(20)     NULL,
    latency_ms              INT UNSIGNED    NULL,
    created_at              DATETIME(3)     NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    PRIMARY KEY (id),
    KEY idx_ai_recommendations_room_created (room_id, created_at DESC),
    KEY idx_ai_recommendations_status (room_id, status),
    KEY idx_ai_recommendations_contract (contract_probability DESC),
    CONSTRAINT fk_ai_recommendations_room
        FOREIGN KEY (room_id) REFERENCES chat_rooms(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='AI 추천 — AIPanelCard, RecommendationCard';
```

## 6. 인덱스 전략

### 6.1 핵심 쿼리 패턴

| 쿼리 | 테이블 | 인덱스 | UI/API |
|------|--------|--------|--------|
| 상담목록 (status 필터 + 정렬) | chat_rooms | `(status, updated_at DESC)` | ChatList, GET rooms |
| 상담목록 (계약확률 우선) | chat_rooms | `(priority_score DESC, updated_at DESC)` | ChatList 정렬 |
| 메시지 infinite scroll | chat_messages | `(room_id, created_at DESC)` | MessageBubble |
| 최신 AI 추천 | ai_recommendations | `(room_id, created_at DESC)` | AIPanelCard |
| 미읽음 카운트 | chat_read_status | `(reader_type, reader_id, read_at)` | ChatList unread |
| 고객 중복 매칭 | customers | `(phone_hash)` | Reception |
| Failover 분석 | ai_failover_log | `(reason, created_at)` | Admin |
| 감사 조회 | audit_logs | `(action, created_at DESC)` | Admin |

### 6.2 복합 인덱스 설계 원칙

1. **ChatList 정렬 (UI §4-2-A):** `status` → `priority_score` → `updated_at` — 앱 레벨 정렬 또는 generated column
2. **Covering Index 회피:** JSON 컬럼(`content`, `tags`)은 인덱스 제외
3. **파티셔닝 (V2.0+):** `ai_logs`, `audit_logs` 월별 RANGE PARTITION
4. **FK 인덱스:** MariaDB FK는 자동 인덱스 미생성 → 명시적 KEY 필수

### 6.3 EXPLAIN 검증 대상

```sql
-- ChatList 기본 쿼리
EXPLAIN SELECT cr.*, c.name, c.tags
FROM chat_rooms cr
JOIN customers c ON c.id = cr.customer_id
WHERE cr.status IN ('new','active') AND cr.deleted_at IS NULL
ORDER BY cr.priority_score DESC, cr.updated_at DESC
LIMIT 20;

-- MessageBubble 페이지네이션
EXPLAIN SELECT * FROM chat_messages
WHERE room_id = ? AND deleted_at IS NULL
ORDER BY created_at DESC LIMIT 50;
```
