### 4.3 ai_call() — 메인 호출

```php
function ai_call(string $system, string $user, array $opt = []): array
{
    $gCfg = ai_config();
    if (empty($gCfg['enabled'])) {
        return ['ok' => false, 'error' => 'AI 전역 킬스위치가 OFF', ...];
    }

    $activeProvider = strtolower($gCfg['provider'] ?? 'anthropic');

    // 단일 프로바이더
    if ($activeProvider !== 'auto') {
        return ai_call_single_provider($activeProvider, $system, $user, $opt, $gCfg);
    }

    // Auto Failover: anthropic → openai → gemini → grok → deepseek
    $failoverChain = ['anthropic', 'openai', 'gemini', 'grok', 'deepseek'];
    foreach ($failoverChain as $prov) {
        $pCfg = ai_config_for_provider($prov);
        if (empty($pCfg['api_key'])) continue;

        $res = ai_call_single_provider($prov, $system, $user, $opt, $pCfg);
        if ($res['ok']) {
            if ($failedProvider !== '') {
                ai_failover_log_insert(...);
            }
            return $res;
        }
        // record failure → next provider
    }
    return ['ok' => false, 'error' => 'Auto Failover 전체 실패', ...];
}
```

## 5. 응답 파싱 및 정규화

### 5.1 프로바이더별 파싱

| Provider | 텍스트 추출 | Token usage |
|----------|-------------|-------------|
| Anthropic | `$data['content'][*]['text']` | `usage.input_tokens`, `output_tokens` |
| OpenAI/Grok/DeepSeek | `$data['choices'][0]['message']['content']` | `prompt_tokens`, `completion_tokens` |
| Gemini | `$data['candidates'][0]['content']['parts'][0]['text']` | `usageMetadata.promptTokenCount` |

모든 provider → **통일 usage 키:**

```php
$usage = ['input_tokens' => (int), 'output_tokens' => (int)];
```

### 5.2 JSON Schema (Structured Output)

| Provider | 메커니즘 |
|----------|----------|
| Anthropic | `output_config.format.type = json_schema` |
| OpenAI/Grok/DeepSeek | `response_format: json_object` + system append |
| Gemini | `generationConfig.responseMimeType = application/json` |

```php
if (!empty($opt['json_schema'])) {
    $json = json_decode($text, true);
}
return ['ok' => true, 'text' => trim($text), 'json' => $json, ...];
```

### 5.3 파싱 실패 처리

- `json_decode` 실패 → `ok=false` → Failover chain 다음 provider
- HTTP ≥ 400 → `ai_log(status='error')` → Failover

### 7.2 캐시 헬퍼 (STEP 4 구현)

```php
function aiGetCachedOrCall(string $cacheKey, int $ttlSec, callable $callFn): array
{
    $cached = redis()->get($cacheKey);
    if ($cached !== false) {
        return json_decode($cached, true);
    }
    $result = $callFn(); // 내부에서 ai_call()
    if ($result['ok']) {
        redis()->setex($cacheKey, $ttlSec, json_encode($result));
    }
    return $result;
}
```

### 7.3 Rate Limiting

| 계층 | 현재 (ai.php) | Production (Rule-005) |
|------|---------------|----------------------|
| Room AI | Session 30s debounce | Redis `rl:ai:room:{id}` 10/min |
| IP | — | Redis `rl:ip:{ip}` 100/min |

```php
function ai_check_rate_limit(string $feature, int $targetId): bool
{
    $key = '_ai_rl_' . $feature . '_' . $targetId;
    if ($now - $last < 30) return false;
    return true;
}
```

## 9. 채팅 플랫폼 통합

### 9.1 End-to-End Sequence

```
Customer → Chat Server → POST /api/v1/chats/{id}/messages
    → INSERT chat_messages
    → IF sender=customer: ai_recommendations pending
    → 201 반환 (동기)
    → [async] ai_mask_pii → ai_call → ai_recommendations complete
    → Redis PUBLISH ai:update → Agent UI AIPanelCard
```

### 9.2 triggerAiPipeline (의사코드)

```php
function triggerAiPipeline(string $roomId, string $messageId): void
{
    if (!ai_check_rate_limit('chat_recommend', (int)$roomId)) return;

    $recId = uuid();
    aiRecommendationRepo->insertPending($recId, $roomId);

    $messages = chatMessageRepo->getRecent($roomId, 20);
    $masked = ai_mask_pii(formatMessages($messages));
    $prompt = ai_load_prompt('recommend');

    $result = ai_call($prompt['content'], buildUserPrompt($masked), [
        'feature'     => 'chat_recommend',
        'target_id'   => $roomId,
        'max_tokens'  => 1536,
        'json_schema' => $recommendSchema,
    ]);

    if ($result['ok']) {
        aiRecommendationRepo->complete($recId, $result['json'], $result);
        redisPublish("acep:room:{$roomId}:events", ['event' => 'ai:update', ...]);
    } else {
        aiRecommendationRepo->fail($recId, $result['error']);
    }
}
```
