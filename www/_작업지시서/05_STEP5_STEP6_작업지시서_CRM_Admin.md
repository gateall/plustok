# 🔴 작업 1: www/06_CRM/01_CRM통합.md 작성

## 목표
상담 종료 시 자동으로 CRM에 데이터 저장하는 워크플로우 설계

## 파일 위치
```
www/06_CRM/01_CRM통합.md
```

## 작성 순서 (11개 섹션)

### 1. 목적(Purpose)
- 상담 → CRM 자동 연동
- 수작업 입력 제거 (CRM Zero-Input)
- 상담 데이터 일관성 보장
- 후속 업무 자동 생성

### 2. 범위(Scope)
- 상담 종료 시 자동 저장
- 상담 요약 + 분류 + 점수 저장
- 고객 정보 업데이트
- 후속 일정 자동 생성
- 이메일/메모 자동 작성

### 3. 요구사항
- 상담 종료 후 5초 내 CRM 저장
- 상담 데이터 완전성 확인
- 개인정보 마스킹 제거 (CRM 내부용)
- 실패 시 재시도 (3회)

### 4. CRM 저장 흐름

```
상담 종료 트리거:
상담원: "상담종료" 버튼 클릭
  ↓
1. 상담 요약 생성 (AI)
   - 고객명, 문의 내용, 상담원 답변 종합
   - 키워드 추출
  ↓
2. AI 분석
   - 분류 (인터넷/대표/CCTV 등)
   - 감정 (긍정/중립/부정)
   - 계약확률 (0~100)
   - 추천 상품
  ↓
3. CRM 업데이트
   - consults 테이블 저장
   - customers 테이블 업데이트
   - ai_summary, category, priority, sentiment, lead_score 저장
  ↓
4. 후속 업무 자동 생성
   - 계약확률 > 50점: 콜 스케줄 생성
   - 고객 정보 불완전: 정보 수집 일정 생성
   - 부정적 감정: 만족도 확인 일정 생성
  ↓
5. 확인 알림
   UI: "상담이 저장되었습니다. [CRM 보기]"
```

### 5. DB 설계 참조
- `consults` - 상담 기록 저장
- `customers` - 고객 정보 업데이트
- `schedules` - 후속 일정 자동 생성
- `ai_logs` - 모든 AI 분석 로그

### 6. API
- POST /api/v1/consults/close
  요청: { room_id, agent_id, summary, feedback }
  응답: { consult_no, crm_saved_at, schedule_ids }

### 7. Business Rule

```
CRM 저장 규칙:

1. 상담 종료 조건
   - 고객과 상담원 모두 동의 (또는 상담원만 가능)
   - 5분 이상 대화 있을 때 (스팸 방지)

2. 자동 저장 항목
   - 상담 요약 (250자 이상)
   - 분류, 감정, 점수
   - 고객 정보 (주소, 연락처 업데이트)
   - 상담원 평가 (optional)

3. 후속 일정 자동 생성
   - 계약확률 > 70점: 3일 후 콜
   - 계약확률 50~70점: 7일 후 이메일
   - 계약확률 < 50점: 30일 후 재접촉

4. 이메일 자동 작성
   - 발신자: 해당 상담원
   - 수신자: 고객
   - 템플릿: 상품별 follow-up 템플릿
   - 발송 여부: 상담원 검토 후 수동 발송

5. 실패 처리
   - 재시도: 지수 백오프 (1s, 2s, 4s, 8s)
   - 최대 재시도: 3회
   - 실패 시 상담원에게 수동 저장 알림
```

### 8. AI Rule
- AI 분석 필수 (자동)
- 프롬프트 버전: v1.0 기본
- 분석 실패 시: 관리자 알림

### 9. Exception
- API 실패 → 재시도
- 데이터 검증 실패 → 상담원 정정 요청
- 고객 정보 중복 → 병합 확인

### 10. Test Case
- 정상 종료 및 CRM 저장
- 네트워크 오류 후 자동 재시도
- 고객 정보 업데이트 검증
- 후속 일정 자동 생성 확인

### 11. Future
- V4.0: 이메일 자동 발송
- V4.5: SMS/카톡 자동 전송
