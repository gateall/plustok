## STEP 5. 로그인 테스트

1. `https://plustok.mycafe24.com/frontend/#/login`
2. Admin과 **동일 ID/비밀번호** 입력
3. JWT 발급 → `/chat` 또는 Dashboard 이동

**API 직접 확인:**
```bash
curl -X POST https://plustok.mycafe24.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"loginId":"YOUR_ID","password":"YOUR_PASSWORD"}'
```
→ HTTP **200**, `accessToken` 포함
