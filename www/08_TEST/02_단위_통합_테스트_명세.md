### 7.2 Mock Scenarios

|--------------|----------|-------|

| `failover` | Provider 1 fail → 2 ok | FO-002, U-AIS-04 partial |
| `all_failed` | All fail | FO-003, U-AIS-04 |
| `timeout` | 11s delay → TIMEOUT | FO timeout branch |
| `rate_limit` | 429 response | FO 429 branch |

### 7.3 MockAiProvider Sample (PHP)

```php
class MockAiProvider implements AiProviderInterface
{
    public function complete(array $messages): array
    {
        $scenario = getenv('AI_MOCK_SCENARIO') ?: 'default';
        return match ($scenario) {
            'all_failed' => ['success' => false, 'code' => 'AI_ALL_FAILED'],
            'failover' => $this->failoverFixture(),
            default => json_decode(
                file_get_contents(__DIR__ . '/../fixtures/ai/recommend_ok.json'),
                true
            ),
        };
    }
}
```

### 7.4 CI Guard

```bash
# Fail build if real API key used in test env
if [ "$CI" = "true" ] && [ "$AI_MOCK_ENABLED" != "true" ]; then
  echo "ERROR: AI_MOCK_ENABLED must be true in CI"

fi
```

| TC-WS-P02 | Auth fail | expired JWT | `connect_error` |
| TC-WS-P03 | Join room | room:join | room:joined |
| TC-WS-P04 | Join forbidden | wrong agent room | error FORBIDDEN |
| TC-WS-P05 | Receive message | POST msg + Redis | message:receive both clients |
| TC-WS-P06 | Typing | typing:start | peer TypingIndicator data |
| TC-WS-P07 | AI update | worker ai:update | ai:update completed |
| TC-WS-P08 | Read update | PUT /read | read:update event |
| TC-WS-P09 | Reconnect | disconnect 5s | rejoin + REST gap fill |
| TC-WS-P10 | Multi-tab | 2 sockets same user | both receive |

### 8.3 REST ↔ WS Dual Send Pattern

| Step | Channel | Verify |
|------|---------|--------|
| 1 | POST /messages | 201 in DB |
| 2 | WS message:receive | Customer receives < 100ms |
| 3 | Compare messageId | REST id === WS payload id |

### 8.4 Flaky Test Mitigation

| Issue | Mitigation |
|-------|------------|
| Race condition | `await once(socket, 'event')` with 5s timeout |
| Port conflict | Random port per test worker |
| Redis lag | Poll up to 2s for event |
| CI resource | Run WS suite nightly, not every PR (V1.0) |
